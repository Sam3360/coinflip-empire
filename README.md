# Coinflip Empire

A small Python experiment exploring probability through 10,000 random coin flips.

## Features

- Simulates thousands of coin flips.
- Calculates heads and tails percentages.
- Finds the longest consecutive streak.
- Compares the results with the expected 50/50 split.
- Generates graphs showing the results and cumulative probability.

## Installation

```bash
python -m pip install matplotlib
```

## Usage

```bash
python coinflip_empire.py
```

The program prints the statistics and generates two graphs.

## What I learned

This project explores how random events behave over many trials and why a fair coin does not necessarily produce exactly 50% heads in every experiment.
